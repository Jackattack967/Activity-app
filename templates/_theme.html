{# Theme bootstrap, included by every page. These are four standalone documents with no shared base, so this partial exists rather than the same six lines copied four times. The script is inline and synchronous on purpose. It has to run before the first paint, or someone who chose dark gets a white flash on every navigation; an external file would be fetched too late. It only reads a saved *override* — with nothing saved, the CSS follows the operating system on its own and this does nothing. It also sets theme-color, which tints the browser's own chrome on a phone. That can't be left to the media-query form of the tag, because a manual override has to win over the OS preference there too. #}
